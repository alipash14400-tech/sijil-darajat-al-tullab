# إعداد نظام أكواد التفعيل

الخدمة تربط كل كود بمعرّف عشوائي محفوظ في متصفح الجهاز، ولا تحفظ الكود الصريح في قاعدة البيانات. بعد التفعيل الأول تُحفظ إفادة موقعة محليًا، فيعمل التطبيق دون إنترنت ما دامت بيانات الموقع محفوظة. عند توفر الإنترنت يتحقق التطبيق من حالة الترخيص؛ لذلك لا يظهر أثر الإيقاف على جهاز غير متصل حتى يعود للإنترنت.

## تجهيز الخدمة عند النشر لاحقًا

1. احتفظ بملف `license-public-key.pem` في جذر المستودع ولا تستبدله بعد إصدار أكواد للمستخدمين.
2. أنشئ قاعدة PostgreSQL وخدمة **Web Service** على Render في المنطقة نفسها. جذر الخدمة `license-server`، أمر البناء `npm ci`، وأمر التشغيل `npm start`.
3. أضف متغيرات البيئة التالية في خدمة الترخيص:
   - `DATABASE_URL`: رابط قاعدة البيانات الداخلي.
   - `APP_ORIGIN`: `https://sijil-darajat-al-tullab.onrender.com`.
   - `ADMIN_KEY`: مفتاح مسؤول طويل وفريد تختاره وتحفظه بأمان.
   - `LICENSE_PRIVATE_KEY_B64`: محتوى الملف المحلي `license-server/private/license-private-key.b64` كاملًا. هذا مفتاح خاص، لا ترفعه إلى GitHub ولا ترسله في المحادثة.
4. بعد حصول خدمة API على رابط Render، عدّل `license-config.js` في جذر المشروع إلى:

   ```js
   window.SIJIL_LICENSE_ENABLED = true;
   window.SIJIL_LICENSE_API_BASE = "https://رابط-خدمة-الترخيص.onrender.com";
   ```

5. ارفع النسخة بعد مراجعتها، ثم افتح `https://رابط-خدمة-الترخيص.onrender.com/admin`، وأدخل `ADMIN_KEY` لإنشاء الأكواد.

لا تُفعّل الخيار في `license-config.js` قبل أن تصبح الخدمة وقاعدة البيانات جاهزتين؛ وإلا سيُقفل التطبيق على المستخدمين ولا يمكن تفعيلهم.

## مفاتيح التوقيع

شُغّل `npm run generate:keys` مرة واحدة من مجلد `license-server`. ينشئ المفتاح الخاص داخل مجلد `private` المستثنى من Git، وينشئ المفتاح العام في جذر الموقع. لا تولّد مفاتيح جديدة بعد إصدار تراخيص؛ المفتاح العام جزء من التحقق دون اتصال.

## حدود ربط الجهاز

معرّف الجهاز هو قيمة عشوائية تحفظ في بيانات المتصفح، وليس رقمًا عتاديًا. مسح بيانات الموقع أو تغيير المتصفح قد يتطلب من المسؤول استخدام «إعادة ربط الجهاز» في صفحة الإدارة. إعادة الربط تسمح بتفعيل الكود على جهاز آخر. إذا أوقف المسؤول كودًا، سيُقفل الجهاز عند أول تحقق لاحق بالإنترنت؛ لا يمكن لخدمة ويب سحب تفعيل جهاز غير متصل فورًا.
